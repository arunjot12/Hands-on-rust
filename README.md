# Hands-On Rust Practice 🦀

Welcome to my **Hands-on Rust** repository! This project serves as a personal playground to explore, test, and master various Rust concepts through practical examples.

## 🚀 Current Examples

### 1. References and Borrowing (`src/ref_mut_ref.rs`)
Demonstrates Rust's ownership and borrowing rules:
- **Immutable borrows** (`&T`): How to pass read-only references to functions.
- **Mutable borrows** (`&mut T`): How to pass references that allow modifying the underlying data.

## 🛠️ How to Run

To run the examples, simply use Cargo from the root directory:

```bash
cargo run
```
